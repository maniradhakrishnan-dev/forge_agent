# 3D Printing DFM Rules & Threshold Targets

All single-part models generated by **ForgeAgent** must satisfy the following Design for Additive Manufacturing (DFM) threshold rules:

## 1. Threshold Parameters

| Rule ID | Parameter | Minimum / Target | Reason |
|---|---|---|---|
| `DFM-01` | Minimum Wall Thickness | $\ge 1.5\text{mm}$ | Prevents structural collapse / thin shell print failures |
| `DFM-02` | Minimum Hole Diameter | $\ge 2.0\text{mm}$ | Prevents nozzle clogging / fused hole interiors |
| `DFM-03` | Max Unsupported Overhang | $\le 45.0^\circ$ | Avoids requiring heavy support structures |
| `DFM-04` | Solid Manifold Check | Watertight (`isSolid == True`) | Ensures clean slicing with zero non-manifold edges |

## 2. Critic Feedback Structure
When a rule fails, the **Part Critic Agent** emits a structured JSON diagnostic:

```json
{
  "rule_id": "DFM-01",
  "status": "FAIL",
  "parameter": "min_wall_thickness",
  "measured": 0.8,
  "required": 1.5,
  "recommendation": "Increase boundary offset or part width near feature to achieve at least 1.5mm wall thickness."
}
```
